## 🎯 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio prático de **Power BI** da **Digital Innovation One (DIO)**. O objetivo principal foi transformar dados brutos de vendas em informações visuais claras, intuitivas e acionáveis, permitindo uma análise profunda do desempenho comercial, identificação de gargalos e suporte à tomada de decisões estratégicas baseadas em dados (Data-Driven).


## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Power BI Desktop:** Ferramenta principal para modelagem, criação de medidas e construção do relatório visual.
* **Power Query (M):** Extração, transformação e limpeza dos dados (ETL), garantindo a integridade e padronização das tabelas.
* **DAX (Data Analysis Expressions):** Criação de colunas calculadas e medidas avançadas (como `SUMX`, `CALCULATE`, `DIVIDE`, entre outras).
* **Git & GitHub:** Versionamento e organização do repositório.
